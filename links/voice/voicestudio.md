# VoiceStudio

<https://github.com/debpalash/VoiceStudio>

Локальный ElevenLabs: клонирование по 3–15 с сэмплу, voice design, дубляж видео, аудиокниги. 16 TTS + 11 ASR движков, 646 языков в каталоге, локальный API и MCP для ботов. 72k★, AGPL-3.0, работает и на CPU.
