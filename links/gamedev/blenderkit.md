# BlenderKit — жидкость

BlenderKit — библиотека ассетов для Blender с аддоном: ищешь прямо в окне 3D-вьюпорта
и ставишь модель или материал одной кнопкой, без скачивания файлов.

Категория **Liquid** — 229 процедурных материалов (шейдеров):
вода (137), гель/слизь (51), пена/пузыри (28), мёд и масло (23), лава (17), кровь (3).
Все бесплатные, лицензия royalty-free.

Что это даёт для геймдева:
- Быстрый прототип воды/лавы/кислоты без написания шейдера с нуля
- Готовые пресеты для рендера трейлеров и скриншотов Steam-страницы
- Материалы процедурные → масштабируются без текстур, не мылятся вблизи
