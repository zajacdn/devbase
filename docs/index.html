Открытая база сервисов, инструментов и ссылок для веб-разработки. Копится из чатов: кидаешь ссылку агенту — она попадает в нужную категорию. Люди открывают сайт, агенты читают docs/data.json.

Репозиторий: github.com/zajacdn/devbase · машинный индекс: data.json · формат: Obsidian-vault (links/<категория>/<слаг>.md)
