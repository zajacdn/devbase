# AGENTS.md — инструкция для AI-агентов

Публичная база ссылок **devbase**. Если тебе дали ссылку на этот репозиторий — это каталог
сервисов и инструментов для веб-разработки. Читай и добавляй, ничего больше не нужно.

## 1. Найти ресурс (самый быстрый путь)

Не клонируй репозиторий целиком ради поиска. Забери индекс и фильтруй локально:

```
https://raw.githubusercontent.com/zajacdn/devbase/main/docs/data.json
```

Формат — массив объектов:

```json
{
  "title": "Lucide Icons",
  "url": "https://lucide.dev",
  "category": "design",
  "tags": ["icons", "svg", "mit"],
  "note": "1500+ иконок, MIT. Пакеты под React/Vue/Svelte + CDN.",
  "added": "2026-10-13",
  "added_by": "Заяц",
  "path": "links/design/lucide-icons.md"
}
```

Поиск: подстрока по `title`, `note`, `tags`, `url` без учёта регистра; при неоднозначности
сначала совпадения в `tags`, затем в `title`. Категории описаны в `build.py` (`CATS`) —
это человекочитаемые названия slug'ов.

Человеческий интерфейс с тем же содержимым: https://zajacdn.github.io/devbase/

## 2. Добавить ресурс

1. Определи категорию (slug из `CATS` в `build.py`; если подходящей нет — предложи новую).
2. Проверь, что домен живой (`curl -sI -L <url>` → 200/3xx; 403 у Cloudflare-сайтов это нормально).
3. Проверь, нет ли дубля: сравни `url` без `www.` и протокола с уже существующими.
4. Создай файл `links/<category>/<slug>.md`:

```markdown
---
title: "Название сервиса"
url: https://example.com
category: design
tags: [icons, svg]
added: YYYY-MM-DD
added_by: кто добавил (имя/ник/агент)
note: "Одна строка: что это и зачем. По делу, без рекламы."
---
```

5. Пересобери статику и закоммить:

```bash
python3 build.py
git add . && git commit -m "add: Название (категория)" && git push
```

Порядок и содержание `docs/` менять руками не нужно — это вывод `build.py`.

## 3. Что не делать

- Не писать секреты, API-ключи, токены, приватные данные — репозиторий публичный.
- Не менять чужие записи без причины: устаревшую ссылку лучше исправить (`note: "мертвая ссылка"` + новая), а не удалять молча.
- Не сваливать несколько ссылок в один файл.
- Не добавлять записи без `note` — пустая карточка бесполезна при поиске.

## 4. Если ты агент, который пришёл от друга Зайца
