# DEVBASE

Открытая база сервисов, инструментов и ссылок для веб-разработки и автоматизации.
Одна ссылка вместо десяти закреплённых сообщений в переписках.

**Портал:** https://zajacdn.github.io/devbase/ · **Машинный индекс:** [`docs/data.json`](docs/data.json)

## Что внутри

Записи разложены по категориям: дизайн и UI, шрифты, AI-модели и API, изображения,
голос и TTS, музыка, платежи, хостинг и деплой, базы и бэкенд, прокси и аккаунты,
код и инструменты, no-code и боты, обучение, SEO, affiliate.

Актуальный список категорий — в начале `build.py` (`CATS`) и в фильтрах на сайте.

## Как найти нужное

- **Человек:** открыть [портал](https://zajacdn.github.io/devbase/), вбить «tts» / «шрифт» / «платёжка» / «прокси».
- **Агент (Hermes, Claude, любой бот):** прочитать `docs/data.json` — массив записей
  `{title, url, category, tags, note, added, added_by}`. Файл публичный, авторизация не нужна.
- **Obsidian:** клонировать репо и открыть папку как отдельный vault — структура папок
  и frontmatter совместимы с Obsidian (wikilinks, теги, свойства).

```bash
git clone https://github.com/zajacdn/devbase.git
```

## Как добавить запись

### Через агента (обычный путь)

Кинуть агенту ссылку или текст — агент вытаскивает заголовок, проверяет что домен живой,
определяет категорию, пишет `links/<категория>/<слаг>.md`, пересобирает сайт и пушит.

### Руками / через PR

1. Создать файл `links/<категория>/<слаг>.md`:

```markdown
---
title: "Название"
url: https://example.com
category: design
tags: [icons, svg]
added: 2026-10-13
added_by: Заяц
note: "Одна строка: зачем это и что внутри."
---

# Название

<https://example.com>

Одна строка: зачем это и что внутри.
```

2. Пересобрать портал и запушить:

```bash
python3 build.py
git add . && git commit -m "add: <название>" && git push
```

Новая категория — добавить slug в словарь `CATS` в `build.py` и создать папку в `links/`.

## Правила

- Одна запись = один файл = одна ссылка. Не сваливать по десять ссылок в один файл.
- `note` — одна-две строки по делу: что это и зачем. Без маркетингового текста с сайта.
- Перед добавлением проверять, что ссылка открывается (живой домен, не 404).
- Платные/закрытые сервисы — помечать тегом `paid`, партнёрские — `ref`.
- Секреты, токены, приватные ключи в репо не кладём никогда.

## Технически

- `links/**/*.md` — источник истины (Obsidian-vault).
- `build.py` — генератор: читает markdown, пишет `docs/index.html` (поиск + фильтры, статика без зависимостей) и `docs/data.json`.
- `docs/` — то, что отдаёт GitHub Pages. Зависимостей нет, только stdlib Python.
